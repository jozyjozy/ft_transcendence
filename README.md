# Transcendance Project

The **Transcendance** project is a web-based application built as part of the **École 42** curriculum. The project aims to create an interactive platform where users can register, log in, play Pong (against other players or an AI), join chat rooms, participate in tournaments, and track their game history.

This full-stack project incorporates web development concepts such as user authentication, real-time communication, and dynamic gameplay. It combines both backend and frontend technologies to create an engaging gaming experience.

## Project Description

**Transcendance** is a web application designed to bring the classic Pong game into the modern age with multiplayer capabilities, chat rooms, tournaments, and a history-tracking system. Players can:

- **Register and log in**: Create an account, log in, and start playing with their friends or against an AI.
- **Play Pong**: A classic Pong game where users can challenge each other or play against an AI bot.
- **Join chat rooms**: Users can join various chat rooms, communicating with other players in real time.
- **Participate in tournaments**: Compete in organized tournaments and earn points based on their performance.
- **Track their game history**: Every match is saved, and users can view their past scores and game statistics.
- **Navigate with history**: The website has an integrated navigation history that tracks the user's actions.

## Features

- **User Authentication**: Secure user login and registration using hashing and salted passwords.
- **Real-time Chat**: WebSocket-powered chat rooms where players can chat with each other while playing.
- **Pong Game**: Playable Pong game where users can challenge one another or play against an AI.
- **Game History**: Tracks scores and matches, and allows users to view their past games.
- **Tournament System**: Organizes and hosts tournaments with leaderboards and score tracking.
- **Navigation History**: Keeps track of the pages users have visited for improved user experience.
- **Multiplayer Mode**: Supports real-time multiplayer games where users can challenge each other.
- **AI Opponent**: A bot that users can play against when no opponents are available.
